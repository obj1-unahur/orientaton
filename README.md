### Resolver las misiones modificando el código

Buscá los archivos `.wlk` desde la columna izquierda de Visual Studio Code para resolver cada desafío.

```
Importante!
Cada vez que modifiques el código para cumplir una misión:
  1. Guardá los cambios en VS Code presionando `Ctrl + S`.
  2. Volvé al archivo `miJuego.wpgm` y tocá de nuevo **Run program**.
  3. Volvé a la ventana del navegador y apretá **F5** (o el botón **Actualizar**) para cargar la nueva versión del juego.
```

### Misión 1: cambiar la ropa del personaje
* Abrí `estudiante.wlk`. Buscá la sección **MISIÓN 1** y cambiá `"rojo"` por otro color disponible (`"azul"`, `"verde"`, `"violeta"`, `"amarillo"`).

### Misión 2: cambiar el saludo
* En `estudiante.wlk`, buscá la sección **MISIÓN 2** y cambiá el texto `"Hola"` por la frase que quieras.

### Misión 3: cambiar la cantidad de materias para recibirte
* En `estudiante.wlk`, buscá la sección **MISIÓN 3** y cambiá el número `5` por el valor que prefieras.

### Misión 4: configurar qué pasa cuando te agarra el 2
* Abrí `cosas.wlk`. Buscá la sección **MISIÓN 4** y borrale las dos barras `//` a las opciones que quieras activar para descomentar el código.
